# Requirements

## User Stories

- As a user, I want to sign up with my name, email and password to the webapp to get an account.
- As a user, I want to login to the webapp to get a registered user session.
- As a registered user, I want to list the products catalog to see what is available.
- As a registered user, I want a product to have a name, description and price to fullfill its information.
- As a registered user, I want to add a product to the shopping cart.
- As a registered user, I want to remove a product from the shopping cart.
- As a registered user, I want to add a repeated product to the shopping cart.
- As a registered user, I want to clean the shopping cart after 5 minutes of inactivity.
- As a registered user, I want to place an order with the products in the shopping cart.
- As a registered user, I want the order to first list my products so I can review what I have added
- As a registered user, I want to enter a delivery address to place my order.
- As a registered user, I want to list my orders with their status to track my orders.
- As a developer, I want an order to has id, date, products with quantities, state and delivery address to identify the order.
- As a developer, I want an order state to be PENDING, CANCELED, PROCESSING or COMPLETED to track the order status.
- As a registered admin, I want to add a product to the system
- As a registered admin, I want to change the status of an order to represent its real status
